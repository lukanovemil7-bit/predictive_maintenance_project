Перед сдачей проекта положите сюда файл demo.mp4 или замените ссылку в README.md на ссылку на видео в облачном хранилище.

Видео должно начинаться с команд:

git clone <ссылка-на-репозиторий>
cd predictive_maintenance_project
pip install -r requirements.txt
streamlit run app.py

Далее нужно показать работу приложения: данные, обучение моделей, метрики, графики и предсказание.
