# Бинарная классификация для предиктивного обслуживания оборудования

## Описание проекта

Цель проекта — разработать модель машинного обучения, которая предсказывает, произойдет ли отказ оборудования. Задача решается как бинарная классификация:

- `0` — отказ оборудования не произошел;
- `1` — отказ оборудования произошел или прогнозируется.

Результат оформлен как многостраничное Streamlit-приложение с навигацией через `st.navigation` и `st.Page`.

## Датасет

В проекте используется набор данных **AI4I 2020 Predictive Maintenance Dataset**. Он содержит технологические параметры оборудования и целевую переменную `Machine failure`.

Основные признаки модели:

- `Type` — тип продукта: L, M, H;
- `Air temperature [K]` — температура воздуха;
- `Process temperature [K]` — температура процесса;
- `Rotational speed [rpm]` — скорость вращения;
- `Torque [Nm]` — крутящий момент;
- `Tool wear [min]` — износ инструмента.

В папке `data/` размещен CSV-файл со структурой, совместимой с AI4I 2020, чтобы приложение запускалось автономно. При необходимости файл можно заменить официальным датасетом UCI или загрузить CSV через интерфейс приложения.

Официальная страница датасета: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
cd predictive_maintenance_project
```

2. Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
```

Для Windows:

```bash
.venv\Scripts\activate
```

Для macOS/Linux:

```bash
source .venv/bin/activate
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

4. Запустите приложение:

```bash
streamlit run app.py
```

## Функциональность приложения

Основная страница приложения позволяет:

- загрузить CSV-файл или использовать датасет из проекта;
- проверить структуру данных и пропущенные значения;
- визуализировать распределение целевой переменной и корреляции;
- обучить несколько моделей машинного обучения;
- сравнить модели по Accuracy, Precision, Recall, F1-score и ROC-AUC;
- построить ROC-кривые и матрицу ошибок;
- выполнить прогноз отказа оборудования по введенным параметрам.

Страница презентации содержит краткое описание проекта, этапов работы, использованных моделей и выводов.

## Обновление официального датасета

Если нужно заменить локальный CSV официальным файлом UCI, выполните:

```bash
python scripts/download_dataset.py
```

После этого перезапустите приложение.
